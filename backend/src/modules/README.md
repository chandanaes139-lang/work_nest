# Backend Modules

| Module | Ownership |
| --- | --- |
| `auth` | Registration, login, sessions, password workflows |
| `users` | Role-aware user identity and account lifecycle |
| `students` | Student profile, academic information, portfolio, certifications |
| `industry` | Company profiles, eligibility, candidate shortlisting |
| `institution` | Cohort management and institutional collaboration |
| `faculty` | Faculty profiles, student monitoring, research workflows |
| `skills` | Skill catalogue, evidence, normalization, mappings |
| `assessments` | Assessment authoring, attempts, and results |
| `opportunities` | Internships, placements, training, projects, programs |
| `applications` | Application submission, decisions, and tracking |
| `matching` | Explainable candidate and opportunity matching |
| `recommendations` | Skill and learning recommendations |
| `analytics` | Readiness, skill gaps, opportunity, and placement analytics |
